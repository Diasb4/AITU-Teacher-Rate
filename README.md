# AITU Prepod — Rate My Professor для Astana IT University

> **Честный студенческий веб-портал отзывов и оценок преподавателей AITU.**  
> Построен на основе реального датасета `dump_parsed.json`: 578 преподавателей, 282 дисциплины, оценки преподавания и строгости прокторинга, реальные студенческие теги (*"+swag +rep"*, *"Chill vibes"*, *"Psychological Horror"*, *"You are cooked lil bro"*).

---

## 🚀 Почему этот сайт без проблем хостится на бесплатных хостингах?

1. **Zero Backend (100% Client-Side SPA)**: Не требует Node.js / Python сервера или внешней базы данных. Все 578 преподавателей и 282 предмета встроены в оптимизированный статический бандл.
2. **Относительные пути (`base: './'`)**: Скрипты и стили загружаются относительно (`./assets/...`), что исключает ошибки 404 на **GitHub Pages** (`https://<user>.github.io/<repo>/`).
3. **Локальное сохранение отзывов (LocalStorage)**: Новые отзывы и оценки, которые оставляют студенты, мгновенно пересчитывают рейтинг преподавателя и сохраняются в браузере.
4. **Мгновенный поиск**: Поиск по фамилии, предмету или тегам работает моментально прямо в браузере без обращения к серверу.

## 🌐 Бесплатный хостинг за 1 минуту

### 1. GitHub Pages (Автоматически через включенный GitHub Action)
1. Запушьте код в свой репозиторий на GitHub (`git push origin main` или `dev`).
2. В репозитории откройте **Settings -> Pages**.
3. В выпадающем меню **Source** выберите **GitHub Actions**.
4. Сайт будет опубликован по адресу: `https://<ваш-логин>.github.io/<имя-репозитория>/`.

### 2. Cloudflare Pages
1. Подключите репозиторий в панели [Cloudflare Pages](https://pages.cloudflare.com/).
2. Параметры сборки:
   - Framework preset: `Vite`
   - Build command: `npm run build`
   - Output directory: `dist`
3. Нажмите **Deploy**.

### 3. Vercel
1. Импортируйте проект на [Vercel](https://vercel.com/new).
2. Framework Preset: `Vite`.
3. Нажмите **Deploy**.

### 4. Netlify (Drag & Drop)
1. Выполните: `npm run build`.
2. Перетащите папку `dist` на [Netlify Drop](https://app.netlify.com/drop).

## 💎 Возможности AITU Prepod

- 🔍 **Каталог 578 преподавателей**: поиск по ФИО, дисциплинам, студенческим тегам, кафедре.
- ⭐ **Двойная оценка**: отдельный рейтинг качества преподавания (1.0 - 5.0) и строгости прокторинга/сессии (1.0 - 5.0).
- 🏷️ **Аутентичные теги студентов AITU**:
  - *Chill vibes*, *Best teacher*, *Favourite teacher*, *+swag +rep*, *Fair game*
  - *Tough but fair*, *Respect is key*, *Attendance is key*
  - *AI Strict*, *Hard grader*, *cringe*
  - *Psychological Horror*, *Pray for your Scholorship*, *You are cooked lil bro*, *Retake*
- ✍️ **Форма оценки преподавателя**: выбор предмета, оценка от 1 до 5 звезд, указание полученной оценки (A, B+, C, Retake), выбор тегов и подробный отзыв.
- ⚖️ **Сравнение преподавателей**: выбор до 3 преподов для сопоставления их оценок, строгости прокторинга и тегов перед записью на дисциплину.
- 🏆 **Зал славы (Лидерборд)**: топы самых любимых преподов, рейтинг хардкорных боссов и самых лояльных на экзаменах.
- 📚 **Гид по дисциплинам (Add/Drop)**: выбор предмета (Calculus, Algorithms, OOP) с мгновенным показом всех преподавателей, которые его ведут, отсортированных по рейтингу.
- 🌗 **Светлая и темная темы**: современный дизайн со стеклянным эффектом (glassmorphism), адаптированный для смартфонов и компьютеров.
